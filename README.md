# AI / ML Projects Collection

This repository is a structured collection of my Machine Learning, Deep Learning, NLP, and Generative AI projects.  
Each project is maintained as an independent Git submodule to keep codebases modular, scalable, and easy to manage.

---

# Repository Structure

## Generative AI Projects
- GENAI-Qwen2-vl-finetuning-ocr  
  Fine-tuning Qwen2-VL model for OCR tasks on image-based text understanding.

- GENAI-GANS-sketch-to-image  
  GAN-based model that converts hand-drawn sketches into realistic images.

- GENAI-LSTM-BiLSTM-image_captioning  
  Image captioning system using LSTM and BiLSTM architectures.

---

## NLP Projects

- NLP-Transformer_using_Pytorch  
  Implementation of Transformer architecture from scratch using PyTorch.

- NLP_Finetuning_Bert_GPT2_T5  
  Fine-tuning multiple transformer models (BERT, GPT-2, T5) for NLP tasks.

- NLP-LSTM_BiLSTM-Urdu_to_RomanUrdu  
  Sequence-to-sequence translation model for Urdu to Roman Urdu conversion using LSTM and BiLSTM.

- NLP-RAG-medical-LLM  
  Retrieval-Augmented Generation (RAG) system for medical question answering using LLMs.
